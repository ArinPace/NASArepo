# How AI tools were used

NASA Space Apps asks every team to describe its use of AI tools. This file is
the working log. The team should edit it before submission.

## Tool

Claude (Anthropic), used through the Claude app with web search and a code workspace.

## What the AI did

- Researched the challenge, the Space Apps rules, and public NASA, JPL and ESA
  data sources.
- Proposed the game concept and wrote the design plan.
- Wrote the code in this repository: the orbital mechanics, the budget and
  flight simulations, the tests, and the interface.
- Drew all graphics in code (charts, spacecraft drawing, orbit view). The
  "postcard" asteroid picture is a simulated view generated by the game and is
  labelled as such. No AI image, video or audio generator was used.
- Drafted this file, the README and the data source list.

## What the team did

- Chose the challenge and set the direction: a realistic game using as much
  real-world data and simulation as possible.
- Reviewed the concept, asked for a simpler explanation, then asked for a more
  detailed, more realistic plan.
- Approved the build and provided the repository.
- (To add: play-testing, balance decisions, the demo, the project page.)

## How the AI's work was checked

- 16 automated tests, most comparing the simulation with published values (see
  DATA_SOURCES.md).
- Full missions were played in a headless browser, solo and with four players.
- Every number that is not from a public source is labelled "game value" in
  the game.
